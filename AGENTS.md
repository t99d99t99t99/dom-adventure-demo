## Input
* Use `event.code` instead of `event.key` unless if you really need to distinguish the language of the typed character.

## Code Structure
* This game requires the players to explore the source code of the game itself.
* To enable the players to do that, you must be extra careful to make the code as human-friendly and readable as possible.
* This game is in korean. Write comments in source codes in Korean.

## Conversation
* Speak English in the conversation.
